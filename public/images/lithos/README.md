# Lithos 视觉素材

原始纹理来自 Poly Haven，按 CC0 授权使用：

- dark_rock_02：https://polyhaven.com/a/dark_rock_02（颜色与法线）
- rock_pitted_mossy：https://polyhaven.com/a/rock_pitted_mossy
- yellow_flower_mulch：https://polyhaven.com/a/yellow_flower_mulch

strata.webp 与 living-strata.webp 由 scripts/lithos/prepare-textures.mjs 对上述素材进行调色、光照和合成制作，共享岩层几何与裁切。执行 node scripts/lithos/prepare-textures.mjs 可重新生成。
