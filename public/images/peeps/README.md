# 人群精灵图

`reborn-crowd` 组件（`app/components/reborn/ui/reborn-crowd`）的演示素材，组件文档、demo 与 `/components` 组件总览页底部的「路人走过」装饰（`app/components/docs/DocsFooterCrowd.vue`）都用它：

- `open-peeps-sheet.png`：3600×2268，透明背景，15 列 × 7 行共 105 个人物，单格 240×324，与组件默认的 `cols` / `rows` 一致。

插画来自 Pablo Stanley 的 [Open Peeps](https://www.openpeeps.com/)，以 CC0 协议发布（公共领域，可商用、可修改、无需署名）。这张拼好的精灵图与 aarivi.com 页脚人群用的是同一份，从该站下载后自托管，不依赖对方服务器。

只用于本站文档，不加入组件 registry：`reborn-ui add reborn-crowd` 只拷贝组件源码，使用方需自行准备精灵图。
