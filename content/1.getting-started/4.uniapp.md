### 配置 `tailwindcss`

首先，请按照 [此指南](https://tw.icebreaker.top/docs/quick-start/install) 安装 `tailwindcss`。

::tip
样式文件可以先不进行创建，稍后我们的脚手架会为您创建，但是需要您手动进行一些配置。
1. [配置 vite.config.ts](https://tw.icebreaker.top/docs/quick-start/v4/uni-app-vite#2-%E9%85%8D%E7%BD%AE-viteconfigts)
2. 在项目目录下的  `main.ts` 或者  `App.vue` 中，添加
::

### 添加依赖

安装以下所需的辅助库。

::code-group

```bash [npm]
npm install -D tailwindcss@3 postcss autoprefixer weapp-tailwindcss vite-plugin-uni-polyfill
npm install @weapp-tailwindcss/variants-v3 @weapp-tailwindcss/merge-v3 @vueuse/core clsx tailwind-variants
```

```bash [pnpm]
pnpm add -D tailwindcss@3 postcss autoprefixer weapp-tailwindcss vite-plugin-uni-polyfill
pnpm add @weapp-tailwindcss/variants-v3 @weapp-tailwindcss/merge-v3 @vueuse/core clsx tailwind-variants
```

```bash [bun]
bun add -d tailwindcss@3 postcss autoprefixer weapp-tailwindcss vite-plugin-uni-polyfill
bun add @weapp-tailwindcss/variants-v3 @weapp-tailwindcss/merge-v3 @vueuse/core clsx tailwind-variants
```

```bash [yarn]
yarn add -D tailwindcss@3 postcss autoprefixer weapp-tailwindcss vite-plugin-uni-polyfill
yarn add @weapp-tailwindcss/variants-v3 @weapp-tailwindcss/merge-v3 @vueuse/core clsx tailwind-variants
```
