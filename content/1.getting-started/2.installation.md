本指南将帮助你在 Vue 或 Nuxt 应用中安装并配置 Reborn UI 组件。

## 开始使用 Reborn UI

::steps

### 配置 `tailwindcss`

首先，请按照 [此指南](https://tailwindcss.com/docs/installation) 安装 `tailwindcss`。


### 初始化脚手架配置

::code-group

```bash [npm]
npx reborn-ui@latest init
```

```bash [pnpm]
pnpm dlx reborn-ui@latest init
```

```bash [bun]
bun reborn-ui@latest init
```

```bash [yarn]
yarn reborn-ui@latest init
```

::


### 添加依赖

安装以下所需的辅助库。

::code-group

```bash [npm]
npm install @vueuse/core motion-v tw-animate-css @iconify/tailwind4
```

```bash [pnpm]
pnpm install @vueuse/core motion-v tw-animate-css @iconify/tailwind4
```

```bash [bun]
bun add @vueuse/core motion-v tw-animate-css @iconify/tailwind4
```

```bash [yarn]
yarn add @vueuse/core motion-v tw-animate-css @iconify/tailwind4
```

::

请参考此指南，在 [Vue 或 Nuxt](https://motion.dev/docs/vue) 中配置 `motion-v`。

### 更新你的 `main.css` 文件

::tip
如果你正在使用 `shadcn-vue` 或 `Nuxt UI`，可以跳过此步骤
::

要配置 `main.css` 文件，请参考 [配置](/getting-started/configuration) 页面。它包含所有必要的 CSS 变量和 Tailwind 配置。

::

::tip{class="mt-12" icon="tabler:check"}
太棒了！你的项目现在已经配置完成，可以使用 Reborn UI 了。
::

### 可选：添加图标支持

许多 Reborn UI 组件和示例会使用 `<Icon>` 组件和 Iconify 图标。虽然这是可选的，但我们强烈推荐安装，以获得更好的使用体验。

要在你的 Vue.js 或 Nuxt.js 项目中添加图标支持，请参考 [Iconify Vue 指南](https://iconify.design/docs/icon-components/vue/)。

### 开始使用 Reborn UI 🚀

现在，你可以在项目中开始使用 Reborn UI 组件了。选择你需要的组件，复制代码，并将其集成到你的应用中。
