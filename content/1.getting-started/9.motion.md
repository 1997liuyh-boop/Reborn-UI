Reborn 的动效收在一个文件里：`app/assets/theme/motion.css`。它只做三件事——定一套**时长阶梯**、定一套**缓动曲线**、给几个高频动作备好**关键帧**。组件不再自己挑 `duration-300` 还是 `duration-350`，改口径时也只改这一处。

曲线不是拍脑袋定的。它们来自一份动画短片在片头写死的运动规范：

```
MOTION  squash/stretch on every body, anticipation before big moves,
        overshoot + settle after, secondary motion (hats, coats, drips)
```

那份短片用一组手写缓动函数实现这套语汇，这里把每条函数拟合成 CSS 能用的形式，名字一一对应。

## 时长阶梯

五档覆盖了组件里实际用到的绝大多数取值（`300` / `200` / `150` / `500` 四个值占了九成以上）。

| 令牌                 | 值      | 用在哪                                 |
| -------------------- | ------- | -------------------------------------- |
| `--duration-instant` | `75ms`  | 悬停变色、图标换色这类不该被察觉的反馈 |
| `--duration-fast`    | `150ms` | 小位移、小尺寸变化                     |
| `--duration-base`    | `200ms` | 默认档，大多数状态切换                 |
| `--duration-slow`    | `300ms` | 展开收起、浮层进出                     |
| `--duration-slower`  | `500ms` | 大面积位移、跨区域转场                 |

Tailwind v4 没有 `duration` 这个主题命名空间，所以时长令牌不会生成 `duration-slow` 这样的工具类，要用 CSS 变量简写：

```vue
<div class="ease-back transition-transform duration-(--duration-slow)" />
```

## 缓动曲线

| 令牌                | 原函数                    | 值                                    | 用在哪                     |
| ------------------- | ------------------------- | ------------------------------------- | -------------------------- |
| `--ease-out`        | `1-(1-u)³`                | `cubic-bezier(0.33, 1, 0.67, 1)`      | 默认出场曲线，最常用       |
| `--ease-out-soft`   | `1-(1-u)²`                | `cubic-bezier(0.45, 0.9, 0.81, 1)`    | 更克制，高频小幅反馈       |
| `--ease-in`         | `u³`                      | `cubic-bezier(0.33, 0, 0.67, 0)`      | 离场，越走越快             |
| `--ease-in-out`     | 三次 in-out               | `cubic-bezier(0.65, 0, 0.35, 1)`      | 位置迁移，首尾都要交代     |
| `--ease-back`       | `easeOutBack`，`c1 = 1.9` | `cubic-bezier(0.35, 1.7, 0.71, 0.95)` | 超调回落，冲过终点约 12%   |
| `--ease-anticipate` | `easeInOutBack` 同口径    | `cubic-bezier(0.73, -0.6, 0.27, 1.6)` | 预备动作，起步先反向退 12% |
| `--ease-spring`     | `1-e⁻⁷ᵘ·cos(16u)`         | `linear(…)` 41 点采样                 | 招牌弹簧，峰值约 1.28      |

前四条是纯缓动，后三条带超调。`--ease-spring` 无法用单条三次贝塞尔表达，改用 `linear()` 逐点采样，末值归一到 1。

::tip
`--ease-out`、`--ease-in`、`--ease-in-out` 覆盖的是 Tailwind 自带的同名令牌。组件里已有的 `ease-out`、`ease-in-out` 因此**自动换成**上表的曲线，不必逐个改写调用处。
::

::warning
`--ease-spring` 峰值 1.28、两次半回弹，幅度相当大。它属于庆祝、点赞这类需要「弹一下」的时刻，**不要**拿它做常规状态切换——列表项每次悬停都弹一下会很吵。
::

## 关键帧

关键帧只交代起止状态，手感全部交给曲线，两者分工不重叠。

| 工具类           | 组成                                                    | 用在哪                        |
| ---------------- | ------------------------------------------------------- | ----------------------------- |
| `animate-pop`    | `reborn-pop` + `--duration-slow` + `--ease-back`        | 浮层、对话框出场              |
| `animate-squash` | `reborn-squash` + `--duration-fast` + `--ease-out-soft` | 按压挤压，对应 squash/stretch |
| `animate-settle` | `reborn-settle` + `--duration-slower` + `--ease-spring` | 落位回弹                      |

`reborn-squash` 横向撑开的同时纵向压扁，总面积基本不变——物体这样才像有重量，而不是单纯被缩放：

```css
@keyframes reborn-squash {
  0% {
    transform: scale(1, 1);
  }
  40% {
    transform: scale(1.06, 0.94);
  }
  100% {
    transform: scale(1, 1);
  }
}
```

## 降低动态偏好

`prefers-reduced-motion: reduce` 下，五个时长令牌一并压到 `0.01ms`：

```css
@media (prefers-reduced-motion: reduce) {
  :root {
    --duration-instant: 0.01ms;
    /* …其余四档同理 */
  }
}
```

这里刻意**不**写 `* { animation: none }` 那种全局封杀。折叠面板的高度过渡、浮层的位移这类动效承担着信息含义，一刀切掉反而让人看不懂界面刚刚发生了什么。压时长的做法只影响走令牌的动效，写死时长的调用处不受影响。
