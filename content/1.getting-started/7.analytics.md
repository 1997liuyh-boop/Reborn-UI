# 数据埋点 (Analytics Event Tracking)

Reborn UI 内置了 `v-track` 指令，用于对用户行为进行埋点（如 Google Analytics 4）。它提供了简洁的语法来处理点击追踪、曝光追踪、停留时长统计以及表单交互追踪。

## 基础用法

### 基础点击追踪

直接传入一个字符串作为事件名称。

```vue
<button v-track="'button_click'">点击我</button>
```

### 带参数的高级追踪

传入一个对象，可以更详细地定义事件名称及自定义参数。

```vue
<button v-track="{ 
  event: 'purchase', 
  params: { price: 99, currency: 'USD' } 
}">
  立即购买
</button>
```

## 进阶功能

### 曝光追踪 (`:view`)

使用 `:view` 参数可以自动追踪元素进入视口（曝光）的事件。

```vue
<div v-track:view="'section_exposed'">
  当元素可见比例超过 15% 时触发。
</div>
```

### 停留时长追踪 (Stay Duration)

在 `:view` 模式下，可以配置 `stay` 参数来追踪用户在某个区域的停留时长。支持单个数值或数组（分档追踪）。

```vue
<!-- 停留 3 秒后触发 -->
<div v-track:view="{ event: 'banner_stay', stay: 3000 }">...</div>

<!-- 分档追踪：分别在 3s 和 10s 时各触发一次 -->
<div v-track:view="{ event: 'article_reading', stay: [3000, 10000] }">...</div>
```

### 表单与 DOM 事件

支持追踪任何合法的 DOM 事件，如 `focus`、`blur`、`mouseenter` 等。

```vue
<input v-track:focus="'search_focus'" v-track:blur="'search_blur'" />
```

### 指令修饰符

- `.once`: 在当前页面生命周期内仅触发一次。
- `.prevent`: 自动调用 `event.preventDefault()`。
- `.duration`: 用于 `:view` 模式，在元素离开视口或卸载时，额外触发一次埋点，并带有 `show_duration` 参数（单位毫秒）。

```vue
<!-- 仅触发一次 -->
<button v-track.once="'mission_start'">开始任务</button>

### 组合配置 (合并曝光与时长)
由于 Vue 限制同一个元素上不能重复使用同名指令，如果你需要同时追踪“进入曝光”和“离屏时长”并使用不同的事件名，可以在对象中嵌套 `duration` 配置：

```vue
<div v-track:view="{ 
  event: 'auth_popup_show', 
  params: { source: 'home' },
  duration: { event: 'auth_popup_stay', params: { type: 'login' } } 
}">
  ...
</div>
```
### 多事件映射 (Multi-Event Map)
由于 Vue 限制同一个元素上不能重复使用同名指令，如果你需要在一个元素上监听多种事件（如同时监听 `focus` 和 `blur`），可以省略指令参数，并传入一个以事件名为键的对象：

```vue
<input v-track="{
  focus: { event: 'input_focus' },
  blur: { event: 'input_blur' },
  // 也支持在映射中嵌套曝光追踪
  view: { event: 'item_view', stay: 3000 }
}" />
```

> [!TIP]
> 当省略指令参数且传入对象时，系统会自动将键名识别为对应的 DOM 事件名或 `view` 曝光追踪。

## 手动追踪

可以使用 `useGtag` 组合式函数进行编程式埋点：

```typescript
const { gtag } = useGtag();

gtag('event', 'custom_action', {
  category: 'navigation',
  label: 'header'
});
```
