# 数据埋点 (Analytics Event Tracking)

Reborn UI 内置了 `v-ga-event` 指令，用于简化 Google Analytics 4 (GA4) 的事件追踪流程。它提供了简洁的语法来处理常见的点击追踪、滚动曝光追踪以及各种常用的事件参数。

## 基础用法

该指令可以应用在任何 HTML 元素或 Vue 组件上。

### 基础点击追踪

直接传入一个字符串作为事件名称。

```vue
<button v-ga-event="'button_click'">点击我</button>
```

### 带参数的高级追踪

传入一个对象，可以更详细地定义事件的名称、类别、标签以及自定义参数。

```vue
<button v-ga-event="{ 
  event: 'purchase', 
  category: 'ecommerce', 
  label: 'pro_plan',
  params: { price: 99, currency: 'USD' } 
}">
  立即购买
</button>
```

## 进阶功能

### 曝光追踪 (View)

使用 `:view` 参数可以利用 `IntersectionObserver` 自动追踪元素进入视口（曝光）的事件。

```vue
<div v-ga-event:view="'section_exposed'">
  当元素被滚动到视口内且比例超过 15% 时，会自动触发追踪。
</div>
```

### 指令修饰符

- `.once`: 该埋点事件在当前页面生命周期内仅触发一次。
- `.prevent`: 自动调用 `event.preventDefault()`，常用于追踪链接点击且希望进行一些异步处理的情况。

```vue
<!-- 仅在第一次点击时触发 -->
<button v-ga-event.once="'mission_start'">开始任务</button>

<!-- 阻止默认跳转进行埋点 -->
<a href="/login" v-ga-event.prevent="'login_click'">模拟登录</a>
```

## 手动追踪

如果不方便使用指令（例如在逻辑复杂的组合式函数中），可以使用 `useGtag` 组合式函数进行编程式埋点：

```typescript
const { gtag } = useGtag();

// 触发自定义事件
gtag('event', 'custom_action', {
  category: 'navigation',
  label: 'header'
});
```
