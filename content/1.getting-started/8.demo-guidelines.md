文档站的组件示例区遵循「一个分组 = 一张卡片」：页面底色是唯一环境层，每个 `DemoSection` 是一张独立卡片（示例区的表面层），卡片内部零填充。每张卡片自带 **收起/展开 · 复制代码 · 预览 · Playground · 询问 AI** 五个动作，源码由分组标题自动抽取，不需要另写一份。

本页与 `app/components/common/demo/demo.config.ts` 同步维护——代码侧以该文件顶部中文注释为唯一事实来源，文档页只做可读展开。新增或改写 demo 前请先读完本节。

## 背景层级：最多两层

```
页面底色 pattern-background          ← ① 环境层（全站唯一，由 layouts/docs.vue 提供）
┌──────────────────────────────────┐
│ DemoSection 卡片  bg + border     ← ② 表面层（每个分组各自一张卡）
│  基础用法          [⌄][⧉][👁][▷][✨] │  ← 卡片头：标题 + 悬停浮出的五个动作
│  ───────────────────────────────  │
│   [ 组件 ]  [ 组件 ]               │  ← 示例本体，无背景
│  ───────────────────────────────  │
│   源码（reborn-collapse 折叠展开）   │  ← 点「展开代码」才出现
└──────────────────────────────────┘
┌──────────────────────────────────┐
│ DemoSection 卡片 · 尺寸            │  ← 分组之间靠 mt-4 分隔
└──────────────────────────────────┘
```

`DemoStage` 的全宽画布**不再自带表面层、也不再有工具条**——分组已各自成卡，画布若再铺一层底就成了「卡中卡」的三层背景；它只是个透明容器，五个动作全部落在每张卡片自己的卡片头上。表面层下放给每张 `DemoSection` 与 `Playground`（默认 `surface`，自成一张卡）。设备档（平板 / 手机）例外：表面层由设备框承担。

卡片内部**禁止**出现 `bg-* + rounded-* + (border | ring | shadow)` 的组合。不要再手写一张卡片把示例包起来——`DemoSection` 已经是那张卡片。

::warning
不要在 demo 里再套 `rounded-2xl border bg-white/60 backdrop-blur-2xl p-8` 这类「卡片套卡片」。文档页已经有大标题，demo 内也不要再写页面级 `<h1>` / `<h2>`。
::

## 唯一例外：内嵌演示体

当被演示的对象本身需要一个「容器」才说得清（滚动容器、拖拽区、水印底、弹层落点、骨架屏占位），允许**一层** `<DemoBlock tone="inset">`：

- 浅填充 + 小圆角
- **无 shadow、无 backdrop-blur、无描边**
- 该层内部不得再出现任何填充盒

这是规范里唯一允许的填充档。其余场景一律 `tone="plain"`（默认）。

## Token 白名单

### 圆角

只用 `rounded-ui-2xs | xs | sm | md | base | lg`（对应 4 / 6 / 8 / 12 / 16 / 24px，定义在 [`app/assets/theme/base.css`](/getting-started/configuration)）。禁止 `rounded-[32px]`、`rounded-2xl`、`rounded-3xl` 这类硬编码或 Tailwind 默认档。

### 颜色

示例脚手架只用语义类：

| 用途 | 类名 |
| --- | --- |
| 表面 / 画布 | `bg-default` |
| 内嵌演示体 | `bg-elevated` |
| 正文 | `text-default` |
| 说明 | `text-muted` |
| 更弱备注 | `text-dimmed` |
| 小节标题 | `text-highlighted` |
| 描边 / 分割 | `border-default` / `divide-default` |

禁止直接写 `gray-100`、`slate-900`、`white/60`、`neutral-*`。项目灰阶是 `gray-1 … gray-10`，**不是** Tailwind 默认的 `gray-50 … gray-950`。

### 间距

| 位置 | 取值 |
| --- | --- |
| 卡片内边距 | `p-6 sm:p-8`（由 `DemoSection` 提供，demo 内不要再垫一层） |
| 卡片之间 | `mt-4`（`DemoSection` 自带，首张归零；不依赖父级 gap） |
| 示例行内 | `gap-4`（`DemoBlock` 默认） |

### 禁用清单

以下类名不得出现在 `app/components/reborn/examples/**`：

- `backdrop-blur-*`
- `shadow-xl` / `shadow-2xl`
- `bg-white/xx`（带透明度的白色填充）
- `bg-slate-*`（色板中不存在）
- 任意 `rounded-[Npx]` 硬编码

组件内部的 `tv()` 配置不在本规范范围内——例如 `RippleCircle` 自身带的 `shadow-xl` 不要为了合规去改组件。

## 共享原语

这些原语位于 `app/components/common/demo/`，已全局自动导入，demo 里直接写标签即可。

### DemoSection

一个 demo 由若干 `DemoSection` 纵向排列而成。每个分组 = **一张独立卡片**：卡片头（小标题 + 可选描述 + 动作组）+ 示例本体 + 折叠源码。卡片本身就是示例区的表面层，内部不得再出现带背景的盒子。

分组同时是**代码单元**：卡片里的内容既是跑起来的示例，也是「复制代码 / Playground / 询问 AI」用的源码——由 `utils/extractDemoSections` 从 demo 文件文本中按 `title` 抽取，**不需要再写一份**。因此：

- 标题必须是字面量 `title="..."`，用 `:title` 动态绑定会抽取失败，该卡片自动隐藏「展开代码 / 复制 / Playground」三个动作（演示照常）；
- 同一个 demo 文件内标题需唯一；
- 片段本身不自洽、需要单独示范时，可用 `code` prop 手写覆盖。

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | `string` | `''` | 小节标题，也可用 `#title` 插槽 |
| `description` | `string` | `''` | 小节描述，也可用 `#description` 插槽 |
| `divider` | `boolean` | `true` | 兼容既有写法；分组已改为独立卡片，分隔靠卡片间距完成，传值不产生视觉差异 |
| `code` | `string` | `''` | 手写源码，覆盖按标题自动抽取的结果 |
| `v-model:open` | `boolean` | `false` | 源码是否展开（折叠动画由 `reborn-collapse` 承担） |

```vue
<DemoSection
  title="基础用法"
  description="一行说清这个分组在演示什么，不要复述文档页已经写过的 API 表。"
>
  <DemoBlock>
    <RebornButton>确定</RebornButton>
    <RebornButton variant="outlined">取消</RebornButton>
  </DemoBlock>
</DemoSection>
```

`DemoSection` / `DemoBlock` 都是单根且未关闭 `inheritAttrs`，调用方传入的 `class` 会落到根节点。需要保留层叠上下文时写 `<DemoSection class="relative z-10">`，不要为此再包一层 `<div>`。

### DemoBlock

只负责「怎么排」，默认不带任何背景。

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `layout` | `'row' \| 'grid' \| 'stack'` | `'row'` | 行内并排 / 网格 / 纵向堆叠 |
| `columns` | `'auto' \| 1 \| 2 \| 3 \| 4` | `'auto'` | 网格列数，仅 `layout="grid"` 有意义；`auto` 沿用「窄屏 1 / sm 2 / lg 3」 |
| `align` | `'auto' \| 'start' \| 'center' \| 'end'` | `'auto'` | `auto` 按 layout 取最自然的默认（row 居中 / grid 等高 / stack 靠左） |
| `tone` | `'plain' \| 'inset'` | `'plain'` | `inset` 是唯一允许的浅填充层 |

```vue
<!-- 一行并排多个组件 -->
<DemoBlock>
  <RebornButton size="sm">小</RebornButton>
  <RebornButton>中</RebornButton>
  <RebornButton size="lg">大</RebornButton>
</DemoBlock>

<!-- 需要容器才说得清的演示体（滚动、拖拽、占位） -->
<DemoBlock tone="inset">
  <RebornScrollbar style="height: 240px">
    <!-- 内容 -->
  </RebornScrollbar>
</DemoBlock>
```

宽内容（如 `DirectionAwareHover` 自身已带 `xl:h-[28rem]`）用 `layout="row"`，不要用 `layout="grid"` 去挤压它。

条目数量固定时显式指定 `columns`，避免 4 项排进 3 列断成 3+1 的孤行：

```vue
<!-- 四种 variant 对照，两列两行铺满 -->
<DemoBlock layout="grid" :columns="2" align="start">
  <DemoItem v-for="v in inputVariants" :key="v" :label="v" mono>
    <RebornInput :variant="v" placeholder="请输入" />
  </DemoItem>
</DemoBlock>
```

### DemoItem

一组同类示例（各种 variant / shape / size 的对照）用 `DemoItem` 给每一项挂上取值标签，不要手写「小标题 + 组件」的 `div`——手写的字号、字重、间距各写各的，排到一起就参差不齐。

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `label` | `string` | `''` | 取值标签，也可用 `#label` 插槽（标签里要写 `<code>` 时用插槽） |
| `note` | `string` | `''` | 条目下方的补充说明（绑定值回显、边界条件），也可用 `#note` 插槽 |
| `mono` | `boolean` | `false` | 标签是否等宽字体；标签是原样的属性取值时传 `true` |

```vue
<DemoBlock layout="grid" :columns="2" align="start">
  <DemoItem label="outlined" mono>
    <RebornInput variant="outlined" />
  </DemoItem>

  <DemoItem :note="`绑定值：${value}`">
    <template #label>
      千分位分隔 · <code>formatter</code>
    </template>
    <RebornInput v-model="value" :formatter="formatThousands" />
  </DemoItem>
</DemoBlock>
```

条目自带的 `note` 优先于在 `DemoBlock` 末尾甩一个 `DemoNote`：说明贴着它所描述的那一项，读者不用回头数第几个才是「第二组」。

### DemoNote

纯文本、无盒子、无背景，取代各处手写的 `text-sm text-gray-500`。

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `text` | `string` | `''` | 说明文字，也可用默认插槽 |
| `tone` | `'muted' \| 'dimmed'` | `'muted'` | `dimmed` 更弱，适合单位、边界条件、事件回显 |

`console.log` / `alert` 不要出现在 demo 里：把最后一次交互写进 `last*` ref，用 `<DemoNote tone="dimmed">` 回显。

## 惯用法

### 内容 vs 脚手架

被演示对象自己的表面要保留（3D 卡片、优惠券票面、流星卡片、图片轮播、对比控件的机身外框），只删掉 demo 作者加上去的 hero 标题、"How to Use" 卡片、图标徽章、光晕 blob、径向渐变衬底、卡片抬升。

判断标准：拿掉这层盒子，被演示的组件是否还说得清自己在干什么？说不清 → 留下并改用白名单 token；说得清 → 删掉。

### 自带表面的组件直接裸渲染

下列组件的 `tv()` 已经画出面板，或本身是 `position: fixed` 的浮层，demo 内容必须裸放，不要再套 `DemoBlock tone="inset"`：

`RebornPopover` / `RebornMenu` / `RebornDropdown` / `RebornNoticeBar` / `RebornHeader` / `RebornToast` / `RebornPopup` / `RebornBackTop` / `RebornAffix` / `RebornFab`

固定定位组件用虚线描边的占位框标出「本来会占据的位置」，占位框**只描边、不填充**：

```vue
<!-- 仅标记落点，本身无背景；真正的按钮由组件 fixed 到视口 -->
<div class="border-default rounded-ui-sm border border-dashed p-6 text-center">
  <DemoNote>回到顶部按钮已固定在视口右下角</DemoNote>
</div>
<RebornBackTop />
```

描边盒（`border` + `rounded-*`，无 `bg-*`）不计入背景层，允许使用。

### 彩色 / 渐变 / 图片主体上的芯片与 CTA

坐在组件自己的彩色表面、渐变或图片上的按钮 / 标签，用 `border-current` 继承主体文字色，这样任意预设、亮暗模式都可读，且不贡献任何填充层：

```vue
<div class="text-white">
  <button
    type="button"
    class="border-current/50 rounded-full border px-4 py-2 text-sm hover:border-current"
  >
    立即加入
  </button>
</div>
```

`border-current` 从祖先继承颜色，所以文字色必须设在芯片的某个祖先上，不要只写在芯片自身。

### 必须在两种模式下都保持深色的表面

项目灰阶 `gray-1 … gray-10` **在亮暗模式之间是对偶翻转的**：亮色下 `gray-1` 是 `#ffffff`、`gray-10` 是 `#1d2129`；暗色下恰好相反。因此**不存在**一个单独的 ramp token 能在两种模式下都保持深色。

流星、星空、发光这类效果如果视觉上依赖深色底，必须显式成对书写：

```vue
<div class="rounded-ui-lg border-gray-8/40 bg-gray-10 px-4 py-8 dark:bg-gray-1">
  <!-- 深色表面上的弱文字用 gray-6：两种模式下都是中灰 -->
  <p class="text-gray-6">在任意深色区块上叠加一层流星动画。</p>
</div>
```

| 意图 | 写法 |
| --- | --- |
| 永久深色底 | `bg-gray-10 dark:bg-gray-1`（`#1d2129` / `#17171a`） |
| 深色底上的弱文字 | `text-gray-6`（`#86909c` / `#929293`，两种模式都是中灰） |
| 深色底上的描边 | `border-gray-8/40` |

不要写 `bg-gray-900` / `border-gray-800` / `text-gray-300`——那些是 Tailwind 默认色板，本项目没有。

### 交互演练场用 Playground，不要手写控制条

需要切换尺寸、颜色、变体时，用全局的 `<Playground v-model :controls :code>`，不要手写一排按钮墙。`controls` 的某项 `props` 依赖响应式值时，`controls` 本身必须是 `computed`；只依赖静态 import 时用普通 `const` 即可。

`select` 控件渲染的是 `RebornSelect`，选项字段是 `options` 不是 `items`。选项列表优先从组件自己的 config 导出（如 `textareaColors` / `textareaSizes`），不要再手抄一份。

左侧控制面板的控件统一 **lg 尺寸**（Playground 内置，demo 无需配置）；「传参明细」完整列出当前所有参数（含等于默认值的项），不做默认值过滤——自定义 `:code` 时也要遵守，布尔项以 `:prop="true|false"` 带值输出保证可直接拷贝。有事件的组件在预览区下方用 `DemoNote` 回显绑定值与最近一次事件参数。完整规范见 `.agents/skills/reborn-web-demo/SKILL.md`。

## 语义 Token 实测值

`bg-default` / `border-default` 这类名字同时存在于 `base.css` 的 `--color-*` 与 `@nuxt/ui` 的 `--ui-*`。**实际生效的是 @nuxt/ui 的 `--ui-*` 命名空间**（它在 `@layer theme` 里后定义，覆盖了同名 utility）。编写 demo 时按下面这张表理解，不要按 `base.css` 的 `--color-default: gray-8` 去猜。

| 类名 | 亮色 | 暗色 |
| --- | --- | --- |
| `bg-default` | 白 `rgb(255, 255, 255)` | 近黑 `rgb(9, 9, 11)` |
| `bg-elevated` | 浅灰 | 深灰 |
| `bg-inverted` | 近黑 | 白 |
| `text-default` | 深灰 | 浅灰 |
| `text-muted` | 中灰 | 中浅灰 |
| `text-dimmed` | 更浅 | 更深（与 muted 对偶） |
| `text-highlighted` | 近黑 | 白 |
| `text-inverted` | 白 | 近黑 |
| `border-default` | 浅细分隔 | 深细分隔 |
| `border-inverted` | 近黑（高对比） | 白 |

「亮色下的黑按钮 / 暗色下的白按钮」用 `bg-inverted text-inverted`，不要自己拼 `bg-gray-10 text-white`。

### 项目灰阶（`gray-1 … 10`）

| Token | 亮色 | 暗色 | 亮色角色 |
| --- | --- | --- | --- |
| `gray-1` | `#ffffff` | `#17171a` | 纯白 / 暗底 |
| `gray-2` | `#f2f3f5` | `#2e2e30` | 分割线、禁用、填充 |
| `gray-3` | `#e5e6eb` | `#484849` | — |
| `gray-4` | `#c9cdd4` | `#5f5f60` | 边框 |
| `gray-5` | `#a9aeb8` | `#78787a` | 占位、禁用 |
| `gray-6` | `#86909c` | `#929293` | 中灰（两种模式都可读） |
| `gray-7` | `#6b7785` | `#ababac` | — |
| `gray-8` | `#4e5969` | `#c5c5c5` | 辅助文字 |
| `gray-9` | `#272e3b` | `#dfdfdf` | 正文 |
| `gray-10` | `#1d2129` | `#ffffff` | 标题 |

脚手架走语义类；只有「必须永久深色」这种语义类覆盖不了的场景才直写 `gray-*`，并且必须成对出现 `dark:` 变体。

## 改写对照

把旧 demo 迁到本规范时，按这一张表机械替换：

| 现状 | 改为 |
| --- | --- |
| 页面级 `<h2 class="text-3xl font-bold">` hero | 删除（md 文档页已有标题）；小节标题降级为 `<DemoSection title>` |
| `<section class="rounded-2xl border bg-white/60 backdrop-blur-2xl p-8">` | `<DemoSection title="…" description="…">` |
| 卡片内再套的 `bg-gray-50/50` 虚线框 | 是演示体 → `<DemoBlock tone="inset">`；否则直接删掉外壳 |
| 多列并排卡片 `grid` + 每格一张卡片 | `<DemoBlock layout="grid">`，格子外壳去掉只留内容 |
| 手写的「小标题 + 组件」`div`（`text-xs` / `italic` 各写各的） | `<DemoItem label="…">`，说明用 `note` 而不是末尾甩 `DemoNote` |
| 手写的 `grid-cols-*` 响应式串 | `<DemoBlock layout="grid" :columns="N">` |
| `text-gray-900 dark:text-gray-100` / `text-gray-500` | `text-default` / `text-muted` |
| `dark:bg-slate-900/40` | 删除 |
| 彩色主体上的 `border-white/40 bg-white/10` 芯片 | `border-current/40`（祖先设好文字色） |
| 必须深色的效果底 `bg-gray-900` | `bg-gray-10 dark:bg-gray-1` |

改完后在 `app/components/reborn/examples` 下确认禁用清单的 grep 为零命中：

```bash
grep -rnE "backdrop-blur-|shadow-xl|shadow-2xl|bg-white/[0-9]|bg-slate-|rounded-\[[0-9]" \
  app/components/reborn/examples --include=*.vue
```
