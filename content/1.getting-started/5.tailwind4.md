### 配置 `tailwindcss`

首先，请按照 [此指南](https://tw.icebreaker.top/docs/quick-start/v4/uni-app-vite) 安装 `tailwindcss`。


### weapp/tailwindcss添加依赖

安装以下所需的辅助库。

::code-group

```bash [npm]
npm install @weapp-tailwindcss/variants @weapp-tailwindcss/merge @vueuse/core clsx tailwind-variants
```

```bash [pnpm]
pnpm add @weapp-tailwindcss/variants @weapp-tailwindcss/merge @vueuse/core clsx tailwind-variants
```

```bash [bun]
bun add @weapp-tailwindcss/variants @weapp-tailwindcss/merge @vueuse/core clsx tailwind-variants
```

```bash [yarn]
yarn add @weapp-tailwindcss/variants @weapp-tailwindcss/merge @vueuse/core clsx tailwind-variants
```
::

::tip
1. 需要将 `tv.ts` 中的 `@weapp-tailwindcss/variants-v3` 改成 `@weapp-tailwindcss/variants` 
2. 在`utils.ts` 中 `@weapp-tailwindcss/merge-v3` 改成 `@weapp-tailwindcss/merge` 
::

### 样式配置
根据先前的配置添加完毕后，可以在：
```js
 UnifiedViteWeappTailwindcssPlugin({
    cssEntries: [
      path.resolve(import.meta.dirname, './src/app.css'),
    ],
  }),
```
你配置的入口文件中上添加：
```css
@import "./base.css";
@import "./typography.css";
```
对应的文件内容：
