## API

| 属性名   | 类型     | 默认值    | 描述                         |
| -------- | -------- | --------- | ---------------------------- |
| `text`   | `string` | `Button`  | 按钮内部显示的文字。         |
| `class`  | `string` | `""`      | 用于样式的额外类名。         |
