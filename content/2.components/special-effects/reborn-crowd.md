## 简介

Crowd 把一张人物精灵图按格切开，每格一个人物，在画布上从左右两侧随机走进走出、边走边上下颠，越靠下的人画在越前面。动画由 gsap 时间线驱动、2D 画布绘制，参考 aarivi.com 页脚的人群；本站组件总览页底部用的就是它。仅 Web 端实现。

数据来源只有一张精灵图：`src` 给图，`cols` × `rows` 决定怎么切，切出的每一格就是一个人物。人群的疏密由 `count` 决定（同时在场的人数上限），节奏由 `duration` 决定（走完一趟的基础秒数，每人再随机放慢，快慢错开）；人物大小不用配置，按画布宽高自动缩放。

其余行为都是自动的：进入视口附近才加载精灵图并开始播放，滚出视口时暂停；系统开启「减少动态效果」时只画一帧静止的人群。状态由 `ready` / `error` 两个事件回报。组件是纯装饰，根节点 `aria-hidden`、不拦截指针，尺寸与遮罩都写在 `class` 上。

### 何时使用

- 文档站、官网的页脚上方需要一段有生气的留白 —— 高度给 13rem~22rem，用 `class` 写一条上沿渐隐的 `mask-image`。
- 空状态、404 页的底部装饰 —— 用 `count` 降到 10~20 人，画面不抢正文。
- 活动页里表现「很多人在用」的氛围 —— 默认全部 105 人上场，`duration` 调小让人群走得更快。

### 何时不使用

- 需要传达信息、可交互的插画 —— 本组件只画装饰，改用 `reborn-image` 放静态插画。
- 满屏的粒子、流星类背景动效 —— 改用 `sparkles` 或 `meteors`。
- 一张图里只有一个角色、想做跟随指针的立体感 —— 改用 `reborn-depth-image`。

## 用法

### 基础用法

传入精灵图 `src`，尺寸写在 `class` 上。默认按 15 列 × 7 行切格（与 Open Peeps 拼图一致），全部人物同时上场。

```vue
<template>
  <RebornCrowd src="/images/peeps/open-peeps-sheet.png" class="h-56 w-full" />
</template>
```

::tip
`npx reborn-ui@latest add reborn-crowd` 只会拷贝组件源码，不含精灵图。演示用的图由 Pablo Stanley 的 [Open Peeps](https://www.openpeeps.com/) 拼成，以 CC0 协议发布（可商用、可修改、无需署名），可以从本站 `/images/peeps/open-peeps-sheet.png` 下载后放进自己项目的 `public/`。
::

### 精灵图的要求

组件把每一格当成一个人物，效果好坏取决于图本身：

| 要求 | 原因 | 不满足的后果 |
| --- | --- | --- |
| 按 `cols` × `rows` 等分，每格同样大小 | 组件按整图宽高平均切格 | 人物被切成两半，或带上相邻格子的一部分 |
| 每格都有人物 | 每格固定占一个上场名额 | 空格子变成看不见的「人」，画面显得稀疏 |
| 有朝向的人物统一面朝右 | 组件把向左走的人水平翻转 | 朝向不一致时一部分人倒着走 |
| 人物底边贴着格子底边，背景透明 | 格子底边就是站位基线 | 人物悬空，或带着底色方块走动 |

半身像（腰部以下被切掉）也能用：最前排的人底边贴住画布底边，切口正好落在画布外；往后站的人被前排挡住下半身。

### 人数与速度

`count` 是同时在场的人数上限，不传时全部格子一起上场，超过格子总数按格子总数算；走完一趟的人回到候场，再随机换一个人上场。`duration` 是走完一趟的基础时长（秒），每人再随机放慢到约 1.05~2.6 倍。

| 组合 | 效果 | 典型用途 |
| --- | --- | --- |
| 不传 `count`、`duration` 默认 14 | 105 人慢慢走，画面饱满 | 组件总览、活动页页脚 |
| `:count="8"` + `:duration="24"` | 稀疏、缓慢，偶尔有人经过 | 空状态、404 页 |
| `:count="40"` + `:duration="8"` | 人来人往、节奏快 | 表现热闹氛围的横幅 |

```vue
<template>
  <RebornCrowd
    src="/images/peeps/open-peeps-sheet.png"
    :count="8"
    :duration="24"
    class="h-44 w-full"
  />
</template>
```

### 渐隐与摆放

组件不带遮罩，也不会自己撑出容器。上沿渐隐写在 `class` 上，后排的人会从内容区里慢慢浮现，而不是被一条硬边截断；人物大小按画布自动缩放（见下表），放在页脚上方时把底边贴住页脚上沿即可。

| 画布条件 | 人物缩放 |
| --- | --- |
| 宽 ≥ 1440px 且足够高 | 精灵图原始尺寸，不再放大 |
| 宽 < 1440px | 按 宽 / 1440 等比缩小 |
| 高度不足 | 人物身高不超过画布高度的 72% |
| 任何情况 | 最小 0.28 倍，窄屏上仍认得出是人 |

```vue
<template>
  <RebornCrowd
    src="/images/peeps/open-peeps-sheet.png"
    class="h-[min(42svh,22rem)] w-full [mask-image:linear-gradient(to_bottom,transparent_0%,#000_12%)]"
  />
</template>
```

::tip
要铺满整个屏幕宽度时，把组件放在有最大宽度的容器之外；不要直接写 `w-screen`，`100vw` 把纵向滚动条也算进去，会撑出横向滚动条。
::

### 加载与事件

组件进入视口上下 200px 范围内才加载精灵图，加载完成、人群就位后派发 `ready`，加载失败派发 `error`（回调参数是图片的 error 事件），画布保持空白。

```vue
<script setup lang="ts">
const status = ref("等待进入视口");
</script>

<template>
  <RebornCrowd
    src="/images/peeps/open-peeps-sheet.png"
    class="h-40 w-full"
    @ready="status = '人群就位'"
    @error="status = '精灵图加载失败'"
  />
</template>
```

## API

### Props

| 属性名     | 类型      | 默认值 | 描述                                                                                         |
| ---------- | --------- | ------ | -------------------------------------------------------------------------------------------- |
| `src`      | `string`  | -      | 精灵图地址，必填。透明背景，按 `cols` × `rows` 等分，每格一个人物，底边贴格子底边，有朝向时统一面朝右。|
| `cols`     | `number`  | `15`   | 精灵图的列数；修改后按新的格子重新切图，不会重新请求图片。                                   |
| `rows`     | `number`  | `7`    | 精灵图的行数；同上。                                                                         |
| `count`    | `number`  | -      | 同时在场的人数上限，超过格子总数按格子总数算；不传时全部人物同时上场，0 表示不上场。         |
| `duration` | `number`  | `14`   | 走完一趟的基础时长，单位秒，最小按 1 秒算；每人再随机放慢到约 1.05~2.6 倍。                  |
| `class`    | `any`     | -      | 追加到根元素的类名，组件尺寸与遮罩写在这里。                                                 |
| `ui`       | `CrowdUI` | `{}`   | 按结构键覆盖各节点样式，键位见「自定义样式（ui）」。                                         |

### Emits

| 事件名  | 回调参数                 | 描述                                                   |
| ------- | ------------------------ | ------------------------------------------------------ |
| `ready` | -                        | 精灵图加载完成、人群就位时触发；`src` 变化后会再触发。 |
| `error` | `(event: Event) => void` | 精灵图加载失败时触发，画布保持空白。                   |

### 自定义样式（ui）

`ui` 按内部结构键覆盖对应节点的类名：

| 键名     | 说明                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `root`   | 根容器，默认 `pointer-events-none relative select-none`，不含尺寸；`class` 也合并到这里，遮罩、透明度写在这里对整片人群生效。 |
| `canvas` | 2D 画布，默认 `absolute inset-0 size-full`。绘制分辨率由脚本按画布尺寸写入，不要在这里改尺寸，改根容器即可。                   |

```vue
<template>
  <RebornCrowd
    src="/images/peeps/open-peeps-sheet.png"
    class="h-56 w-full"
    :ui="{ canvas: 'dark:opacity-90' }"
  />
</template>
```

## 注意事项

- **精灵图不随组件分发**。`reborn-ui add` 只拷贝组件源码，`src` 指向的图要自己放进项目；演示图的来源与授权见「基础用法」。
- **改尺寸、`count`、`duration` 都会重新排一遍人群**。画布尺寸变化后人物大小要重算，组件清场后让人群重新上场、各自随机快进一段，所以窗口缩放时人群会整体换一批位置，这是预期行为。
- **滚出视口即暂停**。视口上下 200px 之外的实例暂停全部时间线并停止重绘，回到视口后从暂停处继续；同一页放多个实例时，只有看得见的那几个在占 CPU。
- **「减少动态效果」随系统设置即时切换**。开启时人群停在当前画面（首次挂载时是随机分布的一帧），关闭后接着走，无需刷新。
- **跨域图片无需 CORS**。组件只把精灵图画上画布、从不回读像素，不同源的 `src` 不带 `crossorigin` 请求，画布被「污染」也不影响显示。
- **画布像素密度上限为 2**。高分屏下按 `min(devicePixelRatio, 2)` 倍绘制，3 倍屏上人物线条会比原图略软。
- **人物不会站到画布上沿以上**。后排的人最高只到画布高度的 20%（且至少离上沿 12px），画布太矮时前后排挤在一起；高度建议不低于 120px。
- **深色背景下不要反相**。Open Peeps 是黑色线稿加白色填充，反相后头发变白、皮肤变黑，像照片底片；嫌白色在深色背景上刺眼时，用 `class` 加 `dark:opacity-90` 压一下。
