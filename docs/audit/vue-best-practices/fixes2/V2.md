## 更新日志

- 破坏 **Anchor / Breadcrumb / Menu**（Web）：导出的注入键 `ANCHOR_INJECTION_KEY`、`BREADCRUMB_INJECTION_KEY`、`MENU_INJECTION_KEY` 由字符串改为类型化 Symbol，按字符串 `inject('reborn-anchor')` 等写法注入的代码会拿到 `undefined`，需改为导入该常量（上一轮 W2-16、W5-15 引入，补记）。
- 破坏 **Cascader / CascaderPanel / Checkbox / CheckboxGroup**（Web）：受控改为严格受控。只传 `:model-value`（Cascader 还包括 `:input-value`、`:popup-visible`）而不接 update 事件时，交互只派发事件，显示保持父值，不再像以前那样点击后接管为内部状态；需要「给初值、之后组件自管」请改用 `defaultValue` / `defaultChecked` / `defaultInputValue` / `defaultPopupVisible`。Checkbox 在父级拒收时原生 input 也会对齐回父值。
- 破坏 **Popover / Popconfirm**（Web）：传入 `open` 后，点击触发器、点击外部、滚动关闭与 `close()` 只派发 `update:open`，不再先改内部显隐；只传 `:open` 不接事件或在事件里拒收，气泡保持父值，与 UniApp 端一致。
- 修复 **Cascader**：`loadMore` 写成内联箭头函数、`fieldNames` 写成内联对象时，父级重渲染（如选中懒加载出来的子项）不再清空已加载的下级；只有替换 `options` 数组、改变 `valueKey` 或 `fieldNames` 的取值、开关懒加载才清缓存。
- 修复 **Pagination**：改每页条数导致当前页越界时，`current-change` 与 `update:modelValue` 只派发一次。
