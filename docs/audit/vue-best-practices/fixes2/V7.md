## 更新日志

- 破坏性 API 变更：无。公开 API（`message.*`、各组件 props / emits / expose）均未改；只有 `reborn-toast.config.ts` 的内部导出调整（删 `messageRenderer`、`hasMessageInstance`，新增 `syncMessageRenderer`、`isMessageContainerActive`、`needsMessageContainer`，`markMessageMounted` / `unmarkMessageMounted` 改收组件实例），仅 reborn-toast 目录内部使用，未进文档。
- **UniApp RebornToast**：修复 tabBar 页面来回切换后，消息只渲染在最后打开的那个（已隐藏的）页面里、当前页看不到的问题。现在每个页面里的 `<RebornToast />`（`RebornPage` 已内置）各自渲染同一份消息队列；H5 自动挂载的命令式容器只在当前页面没有 `<RebornToast />` 时渲染，切回有实例的页面会自动让位。
- **UniApp 端兼容性**：表单控件与 Alert、Badge、Chip、Collapse、Overlay、Popup、Popover、Fab、SlideVerify、SignatureLandscape 等组件依赖的内部属性读取不再使用 `Object.hasOwn`，Toast 不再使用 `Array.prototype.at`，iOS 15.4 以下的小程序 / WebView 不会再在组件 setup 阶段抛 `TypeError`。
- **UniApp RebornSticky**：吸顶状态切换后的内部重测只刷新宽高，不再用跨线程错位的滚动量重算吸顶触发点，临界位置附近不再来回闪动；手动调用 `getRect()` 仍会重算位置。
- **文档站**：未选择过主题色的访客，服务端响应不再附带 `Set-Cookie: theme-color=blue`；只有在主题色选择器里切换后才写入 cookie。
- （无需记录）UniApp RebornWaterfall 的 `remove` / `update` 在本轮恢复了数字 id 与等值字符串互认的旧行为，相对已发布版本没有变化。
