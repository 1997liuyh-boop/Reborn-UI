## 更新日志

- 修复 RebornDialog：服务端渲染初始打开的对话框不再进入共用弹层栈。此前每次请求都会入栈且永不出栈，服务端内存随请求增长，输出的 `z-index` 逐次抬高，与客户端水合不一致。RebornDrawer 共用同一入口，一并受保护。
- 调整 TextReveal：只有插槽文字或 `duration` / `delay` / `stagger` 变化时才重播入场动画。父组件与文字无关的重渲染、`v-for` 里的动态插槽、内联 class 数组不再触发重播；插槽里只有属性（如类名）变化时重建拆分，动画接着原进度播放；`class` / `containerClass` 的类名实际变化时就地重新换行，不重播。行为变化，Props 与插槽不变。
- 修复 RebornDropdown：`options` 中有重复的原始值、数字值与对象项下标相同，或数字和同字面量字符串并存时，选项 key 不再重复，更新时不会错位复用选项。
- 修复 RebornTree：开启 `autoExpandParent` 时，父组件写回与上一次内部写入内容相同的展开集合（如从快照恢复）不再被误判为回流而跳过父链补全。

破坏性 API 变更：无。
