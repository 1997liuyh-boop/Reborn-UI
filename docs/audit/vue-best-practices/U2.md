### [高] RebornInputNumber：`defaultValue` 声明了但从未读取，非受控用法初始值恒为 0；非受控时数值回到 0 也不发 `change`
- 位置：`packages/uniapp-project/src/components/reborn-input-number/RebornInputNumber.vue:18-19`、`:54`、`:147`、`:207`、`:328-336`；文档 `content/2.components/input-and-forms/reborn-input-number.md:15`、`:576`
- 类别：数据流

- 现状：
  ```ts

  defaultValue: 0,                       // 19：全文件再无读取
  const value = ref(props.modelValue)    // 147

  ```
  两个触发条件：①按文档写 `<RebornInputNumber :default-value="5" />`，显示 0；②不绑 v-model 时 `props.modelValue` 恒为默认的 0，用户从 1 减到 0 时 `0 !== 0` 为假，`change` 与表单校验都不触发。

  ```ts

  let committed = value.value
  watch(model, (v) => { if (v !== undefined && v !== value.value) { value.value = v; committed = v } })

  if (val !== committed) { committed = val; model.value = val; emit('change', val); validate?.('change') }
  ```
  并从 `withDefaults` 与 `InputNumberProps` 中删掉 `modelValue`。
- 影响：emits 名称不变（`update:modelValue` 由 defineModel 发出），`modelValue` 的默认值从 `0` 变为不设，未传时由 `defaultValue`（默认 0）兜底，显示不变；需同步文档两端差异表（`reborn-input-number.md:519`、`:793`）与知识库。两端行为对齐 Web。
