## 转交
- `packages/uniapp-project/src/components/reborn-collapse/RebornCollapse.vue` / U1 与整合：布尔模型 default undefined，明确内部默认收起与显式空模型语义；原因：本轮复核 M10 补齐 Web 写法，不能据 Web 实现声明双端已同步。
- `app/components/reborn/examples/reborn-color-picker/RebornColorPickerDemo.vue`（演示，后续批次）：演练场 size 选项去掉 `{ label: "XS", value: "xs" }`，尺寸分节的 `['xs', 'sm', 'md', 'lg']` 改为三档，`sizeColors` 去掉 `xs`，分节描述「size 支持 xs / sm / md / lg 四档」改为三档；原因：Web 端 `size` 类型已收紧为 `sm / md / lg`，`xs` 从来没有对应尺寸类（渲染出来塌成内容大小）。
- UniApp `packages/uniapp-project/src/components/reborn-color-picker/RebornColorPickerPanel.vue` 与 `RebornColorPicker.vue`（第二批 UniApp 分片）：① 面板 `watch(displayValue, emit)` 回传改为只在交互入口提交（触摸拖动、点预设、输入提交），外部改值只同步显示、不回传；② 输入框 `displayValue` 可写 computed 逐字回写，需验证是否有与 Web 端同样的「输到一半被改写」问题，有则同样改为草稿文本 + 失焦 / 确认时提交；③ 外层事件 `onChange` 改名为 `change`（与 Web 端新增的 `change` 对齐，破坏性变更，文档 Emits 表同步合并成一行）；④ 两个组件的 `modelValue` + 手写 `update:modelValue` 改为 `defineModel`（3.4 可用）；⑤ 原始值 `ref` → `shallowRef`。原因：Web 端已按 W3 报告修好，两端同名组件的事件与数据流需一致。
- Web 端是否引入 UniApp 的 `format` / `defaultFormat`（按格式输出 `rgb()` / `rgba()`）：本批未做，属于能力扩展而非缺陷修复；两端差异文档原本已写明。若整合阶段决定对齐，再在 `RebornColorPickerPanel.vue` 的 `outputValue` 里按格式序列化。

## 更新日志
- 调整 **RebornCollapse**（Web）：布尔模型默认 undefined；未绑定时仍从收起开始，显式空值按收起渲染，不借用旧交互状态。
- 修复 **RebornDatePicker**（Web）：文档移除过时的 style 不生效说明，确认原生属性落在触发器根节点。
- 修复 **RebornCollapse**（Web）：绑定 `v-model` 时 `toggle` 事件载荷是切换前的旧值（展开收到 `false`）；现在与文档一致，载荷为切换后的状态。
- 破坏 **RebornCollapse**（Web）：Expose 的 `isAnimating` 改为只读（`Readonly<Ref<boolean>>`），外部不能再改写动画状态。
- 修复 **RebornColorPicker**（Web）：透明度改动没有写回 `v-model`；现在带透明度时输出 `#rrggbbaa`，不透明时仍为 `#rrggbb`。
- 修复 **RebornColorPicker**（Web）：色值输入框边输边被改写，现在失焦或回车时才解析提交，不合法的输入恢复为当前色值。
- 修复 **RebornColorPicker**（Web）：外部改写 `v-model` 会被面板转成小写六位十六进制后回传（颜色名等无法解析的值被改成黑色）；现在外部改值只同步显示、不回传。
- 修复 **RebornColorPicker**（Web）：不绑 `v-model` 时取色无效；改用 `defineModel`，非受控用法由组件自己保存颜色。
- 修复 **RebornColorPicker**（Web）：触屏拖动被系统手势打断后 window 上的监听残留、拖滑块时页面跟着滚动；改用 Pointer Events，卸载时清理。
- 调整 **RebornColorPicker**（Web）：新增 `change` 事件（`RebornColorPickerPanel` 同样提供），一次取色交互结束且颜色变化时派发；表单校验从「拖拽中逐帧」改为在 `change` 时触发一次。
- 破坏 **RebornColorPicker**（Web）：`size` 类型去掉从未生效的 `'xs'`，只接受 `'sm' | 'md' | 'lg'`，与 UniApp 端一致。
- 修复 **RebornCountdown**（Web）：`:value="dayjs(...)"` 内联构造时，父组件每次重渲染都会重启倒计时、重复派发 `change` / `finish`；现在按时间戳判断目标是否变化。
- 修复 **RebornCoupon**（Web）：每次重算都新建 5 组媒体查询且卸载后不释放，长时间停留或反复进出页面时监听持续累积。
