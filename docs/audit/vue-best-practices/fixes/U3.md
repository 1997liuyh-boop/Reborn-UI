## 写法统一

- 应用 vue-best-practices 技能及 reactivity / sfc / component-data-flow / composables 四个核心参考；UniApp 仅使用 Vue 3.4.21 已有 API，模板引用保留 ref。
- Slider、Switch、Textarea、Tabbar 使用 defineModel；布尔模型缺省为 undefined。Transition 接口式 Props，Slider/Tabbar/Textarea/Transition 事件类型化。
- 原始值、整体替换的测量结果及 Promise 句柄使用 shallowRef；Waterfall columns 因 push/字段就地更新保留深 ref，内部 heights 使用普通数组。
- 派生状态使用 computed，SlideVerify 动态插槽在渲染期判断；Slider 刻度、Tabs 标签类、Toast 消息样式按依赖缓存。
- 移除 SwiperAction 死滚动/手势状态、Sticky 无效函数、Text 常量 key、Waterfall 无效主题变体；组件名统一为 RebornTextarea。条件编译与原有 rpx 几何保留；Waterfall gutter 现有 px 公开契约保留。
