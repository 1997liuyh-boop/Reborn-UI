## 写法统一
- UniApp 仅使用 Vue 3.4 API，模板引用保持 ref；二维码配置整体替换用 shallowRef。
- 只对已确认原始值转换shallowRef；保留深层修改列表/对象、枚举选择模型待定的数组及模板引用ref。
