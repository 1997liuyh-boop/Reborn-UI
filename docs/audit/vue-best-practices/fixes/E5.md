## 写法统一

- 原始值及仅整体替换的状态使用 shallowRef；Playground 配置如果同时由嵌套 v-model 就地回写（如 TimePicker 的 state.value），必须保留 ref。静态树、选项、文本与 controls 保持普通常量。
- Web 模板引用使用 useTemplateRef，组件命令式能力以真实组件类型约束。Scrollbar 导入真实目录 scrollbar，删除重复维护的 ScrollbarExposed / ScrollToOptions。
- 只有深层写入依赖继续保留 ref；以下是最终 AST 清单。没有为了形式统一将它们强改为 shallowRef。

|---|---|

| `reborn-time-picker/RebornTimePickerDemo.vue` | `state`、`formats`、`rangeValue` |
| `reborn-timeline/RebornTimelineDemo.vue` | `playgroundActivities` |

- 现有 Tailwind 样式保留；新注释为中文，未向模板加入 TypeScript 断言或下划线方法。
- 收口统一类型快照中的 Tabs 联合类型、Text 语义色、Transfer 数据记录和 unknown 插槽值、Typewriter 索引边界。Transfer 采用有约束的 DemoTransferItem 类型，没有新增无约束 any 来绕过诊断。
