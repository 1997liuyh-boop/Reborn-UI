## 写法统一

- 全片原始值、整体替换的对象/数组改 shallowRef，包括 SKU 选择模型、句柄和 Dayjs。Playground 嵌套 state、SearchBox 的 outerSlotValue.selectValue / skuSearchValue.language 等就地修改对象保留 ref，不破坏深层更新。
- Popover、Rate、Statistic、Select 表单及 Table 模板引用改有类型 useTemplateRef。所有新增注释中文、外观使用 Tailwind；未新增模板 TS 断言、下划线方法名或无约束 any。
- 收口统一快照中的 7 个类型诊断：Rate size/color/trigger 显式联合类型；Segmented 使用 field-names，槽 item 按 object/primitive 收窄；Slider 使用平铺 value/active/disabled，外形走 ui.thumb，组件负责位置、键盘和焦点。
- SearchBox 裁定：brief 将 UniApp 业务收口误扩展到 Web。经协调者确认，以当前 Web 源码和文档为准，保留有效 showDropdown、leading、trailing、input-leading、input-trailing、dropdown，不误换为 UniApp prefix/extra。演练场补 v-model:history，本地样例 historyKey 独立；测试验证 showDropdown/size/shape 控件、外部历史回写和存储键隔离。
- 保留 Table 远程 watch onCleanup、可写 radio computed；Statistic onMounted 初始化；Progress 手动推进且无后台 timer。
