### [高] BalanceSlider / GradientButton / LineShadowText 演示：用 `@vueuse/core` 的 `useColorMode` 读明暗，挂载即按系统偏好改写 `<html>` 的 class，把站点主题切掉
- 位置：
  - `app/components/reborn/examples/balance-slider/BalanceSliderDemo.vue:2`、`:6`
  - `app/components/reborn/examples/gradient-button/GradientButtonDemo.vue:2`、`:6`
  - `app/components/reborn/examples/gradient-button/GradientButtonOverview.vue:5`、`:9`（总览缩略图，挂载后不卸载）
  - `app/components/reborn/examples/line-shadow-text/LineShadowTextDemo.vue:2`、`:5`
- 类别：生命周期与清理 / 组件边界
- 依据：
  - `references/composables.md`「状态按预期作用域只创建一次，传递或注入同一个实例；在每个消费者里各调一次有状态 composable 往往会造出独立副本」。站点的明暗状态由 `@nuxtjs/color-mode` 持有，这里另起了一份独立状态，还会反向写 DOM。
  - `references/reactivity.md`「computed 只做派生，副作用放 watcher」：这里本意只是派生一个颜色，引入的却是一个会写全局 DOM 的有副作用 composable。
- 现状：
  ```ts
  import { useColorMode } from "@vueuse/core";
  const colorMode = useColorMode();
  const isDark = computed(() => colorMode.value == "dark");
  ```
  已对照本仓库安装的 `@vueuse/core` 14.2.1 源码（`dist/index.js:2039-2109`）核实：
  1. 它自带一份状态，存在 `localStorage['vueuse-color-scheme']`，默认 `'auto'`，即跟随系统偏好，与站点的 `nuxt-color-mode` 无关。
  2. `watch(state, onChanged, { immediate: true, flush: 'post' })` 加 `tryOnMounted(() => onChanged(state.value))`：挂载时一定执行一次，把 `<html>` 上的 `dark` / `light` 换成自己算出的值，同时插一段禁用过渡的 `<style>`。
  3. 卸载后不会还原。`@nuxtjs/color-mode` 只在偏好变化时写 class，不会纠正回来。

  触发条件很常见：`nuxt.config.ts:183-186` 把站点默认设为 `preference: "dark"`，而多数访客系统是浅色。这类访客打开 BalanceSlider、GradientButton、LineShadowText 任一文档页，整站就从暗色跳到浅色；离开该页仍停在浅色，直到手动切一次主题。`GradientButtonOverview` 挂在组件总览页且不卸载，打开总览页就会触发，并在页面存续期间持续跟随系统偏好改写。

  附带问题：`isDark` 反映的是系统偏好，不是站点当前主题，用户手动选了暗色而系统是浅色时，按钮底色 / 阴影色本身也取反。
- 改法：去掉 `@vueuse/core` 的导入，改用 Nuxt 自动导入的 `useColorMode()`（`@nuxtjs/color-mode`，只读当前主题，不写 DOM）。仓库里已有正确写法 `BalanceSliderOverview.vue:11-14`，注释也写明了原因：
  ```ts
  // 删掉 import { useColorMode } from "@vueuse/core"
  const colorMode = useColorMode()
  const isDark = computed(() => colorMode.value === 'dark')
  ```
  能用 CSS 变量解决的直接不读模式更好，例如 `LineShadowTextOverview.vue:15` 用 `shadow-color="var(--ui-text-highlighted)"`，明暗自动切换，连 composable 都不需要。
- 影响：
  - 只改演示，不动组件公开 API。
  - 演示是知识库 `examples` 的来源之一，改后要 `pnpm kb:build --only balance-slider gradient-button line-shadow-text`；如有文档引用了这段代码也要同步。
  - 组件 `app/components/reborn/ui/scroll-island/ScrollIsland.vue:3`、`:24` 有同样写法（还放在 computed 里，每次求值都新建一份），不属于本分片，交 W 分片处理。

  const timers = new Set<ReturnType<typeof setTimeout>>()
  /** 每次开始流程自增，旧流程的回调据此判断自己是否已过期 */
  let runId = 0

  function settle(key: keyof typeof pending, delay: number, id: number) {
    return new Promise<void>((resolve) => {
      const timer = setTimeout(() => {
        timers.delete(timer)
        if (id !== runId) return
        pending[key] = false
        resolve()
      }, delay)
      timers.add(timer)
    })
  }

    timers.clear()
    asyncLoading.value = false
  }
