### [中] RebornCollapse：文档 UniApp 端仍写「点击不回写 v-model / 从不派发 update:modelValue / 默认 false」，与当前 UniApp 源码相反
- 类型：新问题
- 原条目：无
- 位置：`content/2.components/miscellaneous/reborn-collapse.md:56`、`:153`、`:178`、`:215`、`:272`、`:282`；`knowledge/overrides/reborn-collapse.json`（「UniApp 模型默认值待整合同步」）
- 依据：`references/component-data-flow.md`「`v-model` 用于真正的双向契约」；VERIFY-METHOD「文档改动与源码不符」
- 现状：UniApp 端已改为 `defineModel<boolean>({ default: undefined })` + `useBooleanModel('modelValue')`（`packages/uniapp-project/src/components/reborn-collapse/RebornCollapse.vue:22-23`），`toggle()` 写 `collapse.value`（同文件 `:66`），`useBooleanModel` 的 setter 每次都 `instance.emit('update:modelValue', value)`（`packages/uniapp-project/src/composables/useBooleanModel.ts:11-15`）。也就是说 UniApp 点击触发区**会**回写 `v-model`，而文档仍写：
  ```md
  UniApp 端点击触发区只改组件内部状态，**不会回写** `v-model`，外部绑定值会与界面不同步；
  | `modelValue`  | `boolean` | `false` | 展开状态初值与外部控制；点击触发区不会回写 …
  | `update:modelValue` | `(value: boolean)` | 由 `defineModel` 声明，但组件内部从不派发，点击不会更新外部值。 |
  ```

- 依据：`references/composables.md`「Keep related state, actions, and lifecycle cleanup together」——同一事件只登记一处
- 现状：`useFloatingDismiss` 专门提供了 `onViewportScroll`（注释写明「共用捕获阶段的滚动监听维护浮层位置，避免宿主重复登记」），ContextMenu 没用，展开期间又自己 `window.addEventListener("scroll", schedulePositionUpdate, true)`，每次滚动两个捕获监听各跑一次。`useFloatingDismiss.ts:7-8` 仍写「RebornContextMenu 仍自行监听 mousedown，未接入本 hook」，与现状相反，后来者会据此误判。
- 建议改法：给 `useFloatingDismiss` 传 `onViewportScroll: schedulePositionUpdate`，删掉 `syncOpenListeners` 里的 `scroll` 登记；更新 `useFloatingDismiss.ts` 头注释（该文件属组合式函数分片，转交协调者）。

### [低] RebornTabs / RebornTimeline：根节点变成 Fragment，组件 `$el` 拿不到根元素，外层 `<Transition>` 无法过渡
- 类型：新问题
- 原条目：无
- 位置：`app/components/reborn/ui/reborn-tabs/RebornTabs.vue:149-156`、`:821`；`app/components/reborn/ui/reborn-timeline/RebornTimeline.vue:79`
- 依据：`references/component-transition.md`（`<Transition>` 只能作用于单个元素根）；`references/component-fallthrough-attrs.md`
- 现状：
  ```vue
  <TabsFrame v-slot="view" :view="getView()"> <div v-bind="$attrs" ...> … </TabsFrame>
  <ol v-for="view in [getView()]" :key="view.id" v-bind="$attrs" :class="view.rootClass">
  ```
  两处都是为了在模板里得到一个「本次渲染的局部变量」。`TabsFrame` 是函数式组件，返回插槽数组会被规范成 Fragment；Timeline 根上的 `v-for` 同样编译成 Fragment。结果两个组件的 `$el` 都是 Fragment 的起始文本锚点，页面根节点就是 `<RebornTabs>` 时页面级 `<Transition>` 会告警「renders non-element root node」并失去过渡，使用方拿 `ref.$el` 测量或滚动也会失效。属性透传已改为手动 `v-bind="$attrs"`，这部分没有问题。
- 建议改法：局部视图改成 `computed`（`const view = computed(getView)`），模板直接 `<div v-bind="$attrs" :class="ui.root">` / `<ol …>` 作单一根；需要每次渲染都重新求值插槽时，在 `onBeforeUpdate` 里递增一个版本号让 `computed` 失效（与 `RebornDescriptions.vue:210-214` 同一做法）。

### [低] RebornTimeline：`items` 模式把整条数据展开成节点 props，业务字段会落成 DOM 属性
- 类型：新问题
- 原条目：无
- 位置：`app/components/reborn/ui/reborn-timeline/RebornTimeline.vue:56`
- 依据：`references/component-fallthrough-attrs.md`「Fallthrough attributes … wrapper components must forward attrs safely」
- 现状：`h(RebornTimelineItem, { ...item, key: item.key ?? index })`。HEAD 逐项传入声明过的字段；现在 `items` 里任何未声明的字段（后端返回的 `id`、`userId`、嵌套对象等）都会作为透传属性落到每个 `<li>` 上，例如 `id="1"` 在多个时间线之间重复、对象字段渲染成 `[object Object]`。
- 建议改法：按 `TimelineItemData` 的已知字段挑选后再传（或给 `RebornTimelineItem` 设 `inheritAttrs: false` 只转发 `class` / `style`）。

### [低] RebornTimePanel：整面板 `disabled` 时，所有选项都套禁用样式，选中项不再高亮
- 类型：新问题
- 原条目：无（W7「每次状态变化都重渲染全部选项」整改的副作用）
- 位置：`app/components/reborn/ui/reborn-time-picker/TimePanelOptions.vue:21-24`
- 依据：SKILL.md「Refactors preserve existing behavior」
- 现状：
  ```ts
  function isDisabled(value: number) { return props.disabled || !props.available.has(value); }
  function itemClass(value: number) { return isDisabled(value) ? props.classes.disabled : props.value === value ? props.classes.active : props.classes.idle; }
  ```
  HEAD 的类名只按规则禁用（`isDisabledValue`）判断，整面板禁用时仍显示选中项的 active 样式，`aria-disabled` 才并入 `disabled`。现在类名也并入了 `props.disabled`，独立使用的禁用面板看不出当前选中的是哪一项。
- 建议改法：类名用 `!props.available.has(value)` 判断禁用，`aria-disabled` 继续用 `isDisabled(value)`；`v-memo` 依赖相应拆开。

### [低] RebornTable：整表内容 MutationObserver 对所有表格常驻，未开溢出提示时也在监听
- 类型：新问题

- 建议改法：在 `TABLE_OVERFLOW_KEY.observe` 首次登记时再懒创建 MutationObserver，最后一个登记注销时断开。
