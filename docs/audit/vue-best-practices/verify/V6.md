### [高] RebornPopup：抽出的 RebornPopupPanel 让小程序端弹层标题永远不显示
- 类型：修复有误
- 原条目：U2 [低] RebornPopup：portal 与非 portal 两个分支各写了一遍约 40 行几乎相同的模板
- 位置：`reborn-popup/RebornPopup.vue:520`、`:554`；`reborn-popup/RebornPopupPanel.vue:78-81`、`:85-88`；受影响调用方 `reborn-select/RebornSelect.vue:369`、`reborn-cascader/RebornCascader.vue:494`、`reborn-date-picker/RebornDatePicker.vue:604`
- 依据：`references/component-slots.md`（可选插槽与后备内容）；uni-mp-compiler `dist/transforms/vSlot.js` 的 `transformSlot` 按 `<template #name>` 静态收集插槽名写入 `u-s`、不看 `v-if`；`dist/template/codegen.js:150-220` 在 `fallbackContent: false`（`uni-mp-weixin/dist/uni.compiler.js:148-151`）时把后备内容编译成 `$slots.xxx` 的 `wx:if / wx:else`；`uni-mp-weixin/dist/uni.mp.esm.js:436-444` 子组件的 `$slots` 由 `uS` 生成
- 现状：
  ```vue
  <!-- RebornPopup.vue -->
  <template v-if="$slots.header" #header><slot name="header" /></template>
  <!-- RebornPopupPanel.vue -->
  <slot name="header"><text :class="rootClass.title()">{{ title }}</text></slot>
  ```
  用仓库内 `@dcloudio/uni-mp-compiler` 编译当前两个文件：Popup 两处都输出 `<reborn-popup-panel … u-s="{{['header','d']}}">`，Panel 的 header 输出 `<block wx:if="{{$slots.header}}"><slot name="header"/></block><block wx:else><text …>{{g}}</text></block>`。`$slots.header` 恒为真，标题后备进不了 `wx:else`；Popup 转发的 `<view wx:if="{{p}}" slot="header">` 在使用方没写 header 时又不渲染，header 行只剩关闭按钮。触发条件：微信小程序上任何只传 `title`、不写 `#header` 的 Popup，RebornSelect / RebornCascader / RebornDatePicker 的弹层标题全部消失。H5 用的是 Vue 运行时的真实 `$slots`，不受影响。整改前标题后备写在 Popup 自己的模板里，Popup 的 `$slots` 来自使用方的 `u-s`，是准确的。
- 建议改法：Panel 不用「插槽后备内容」兜底标题。Popup 算出 `hasHeaderSlot = !!useSlots().header`（来自使用方，两端都准确）作为 prop 传给 Panel；Panel 改成 `<slot v-if="hasHeaderSlot" name="header" /><text v-else :class="rootClass.title()">{{ title }}</text>`；Popup 转发处去掉 `v-if`，直接 `<template #header><slot name="header" /></template>`。改后在微信开发者工具验证「只传 title / 传 #header」×「rootPortal 开 / 关」四种组合，并回归 Select、Cascader、DatePicker 的弹层标题。

### [高] RebornCollapse：展开 300ms 后外壳高度放开为 auto，绝对定位的内容不撑高，面板塌成 0
- 类型：修复有误
- 原条目：U1 [中] RebornCollapse：展开高度只在打开时测一次并写死为 px，内容之后再变高会被裁切
- 位置：`reborn-collapse/RebornCollapse.vue:45-62`、`:68`、`:84-85`；`reborn-collapse/reborn-collapse.config.ts:4-5`；文档 `content/2.components/miscellaneous/reborn-collapse.md:213-216`、`:283`
- 依据：`references/component-transition.md` 高度动画部分；CSS 规则：绝对定位子节点脱离文档流，不参与父级 `height: auto` 的计算
- 现状：
  ```ts
  transitionTimer = setTimeout(() => {
    if (current === token) height.value = isOpened.value ? null : 0   // null → height: auto
  }, isOpened.value ? 300 : 20)
  ```
  ```ts
  trigger: 'relative overflow-hidden transition-[height] duration-300 ease-in-out',
  content: 'absolute top-0 left-0 w-full',
  ```

### [低] RebornSelect：options 引用变化会重置弹层里未确认的滚轮位置
- 类型：新问题
- 原条目：无（U2-23 合并 watcher 时引入）
- 位置：`reborn-select/RebornSelect.vue:344`
- 依据：`references/reactivity.md`「Use watchers for side effects」——草稿状态不应被无关的依赖变化覆盖
