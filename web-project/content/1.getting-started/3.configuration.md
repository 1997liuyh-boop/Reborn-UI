## 主题变量

基础配置参考地址在[APP规范化](https://mastergo.com/file/178064843889552?page_id=9169%3A76702&shareId=178064843889552)；我们需要按照APP规范化中的主题变量进行配置。

::tip
项目的基本变量设计参考链接如下
1. [什么是主题变量？](https://tailwindcss.com/docs/theme)
2. [主题变量命名空间文档](https://tailwindcss.com/docs/theme#theme-variable-namespaces)
3. [默认主题变量引用](https://tailwindcss.com/docs/theme#default-theme-variable-reference)
::

::cssfile-tree-viewer
---
defaultFile: assets/css/main.css
tree:
  - assets:
    - css:
      - main.css
    - theme:
      - base.css
      - typography.css
---
::

---
